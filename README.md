## 📋 About This Project
A deep learning CNN model that analyzes chest X-Ray
images and detects pneumonia with **88.62% accuracy.**
Built as a complete web application using Flask.

## 🎯 Results
| Metric | Score |
|--------|-------|
| Test Accuracy | 88.62% |
| Pneumonia Detection | 91% |
| Normal Detection | 85% |
| Total X-Rays Trained | 5,216 |
| Total Dataset | 5,840 |

## ✨ Features
- ✅ Upload Chest X-Ray image
- ✅ AI diagnosis in seconds
- ✅ Confidence score display
- ✅ Patient details form
- ✅ Download PDF medical report
- ✅ Risk level assessment

## 🛠️ Tech Stack
- **Deep Learning** → TensorFlow / Keras
- **Web Framework** → Flask
- **Image Processing** → OpenCV
- **Data Analysis** → NumPy, Pandas
- **Visualization** → Matplotlib
- **PDF Reports** → ReportLab
